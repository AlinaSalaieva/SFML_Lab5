# Лабораторна робота №5: Використання SFML в C++ проєкті

**Варіант 21:** Моделювання руху кулі по східчастій поверхні  
**Виконала:** студентка групи 3-8 Салаєва А.В.  

---

## Опис проєкту
Мета роботи — отримати навички створення та налаштування C++ проєктів за допомогою системи складання **CMake**, пакетного менеджера **vcpkg** та графічної бібліотеки **SFML**.

У цьому проєкті реалізовано:
* Фізичну модель руху кулі під дією гравітації, її горизонтальний рух та зіткнення (колізії) зі сходинками й межами екрана.
* Графічний інтерфейс на базі бібліотеки SFML (малювання сходинок, кулі та траєкторії руху).
* Керування параметрами симуляції в реальному часі за допомогою клавіатури.

---

## Технології та інструменти
* **Мова програмування:** C++ (стандарт C++17)
* **Графічна бібліотека:** SFML (3.x)
* **Пакетний менеджер:** vcpkg (у режимі маніфесту `vcpkg.json`)
* **Система збирання:** CMake (з використанням `CMakePresets.json`)
* **Середовище розробки:** Visual Studio / VS Code

---

## Структура проєкту
```text
SFML_Lab/
├── CMakeLists.txt        # Конфігурація CMake
├── CMakePresets.json     # Пресети конфігурації з інтеграцією vcpkg
├── vcpkg.json            # Маніфест залежностей (SFML)
├── main.cpp              # Головний вихідний код програми
└── build/                # Директорія збірки (створюється автоматично)
